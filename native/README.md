# Kleenest Native Foundation

The modular web application remains the production feature source. Native shells consume the same platform-neutral navigation, activity, reward, auth, analytics, partner, and Supabase boundaries.

## Surfaces

Home · Maps · Route · Details · Social · Profile · Business · Enterprise · Admin

## Native rules

- Keep business logic in shared modular services.
- Keep credentials out of source control.
- Use Supabase publishable keys only in clients.
- Use native deep links for mobile auth callbacks.
- Keep platform-specific UI in the shell.
- Keep attribution, rewards, permissions, and business rules server-authoritative.

## Targets

- iOS: Swift/Supabase Swift foundation
- Android: Kotlin/Compose/Supabase Kotlin foundation
- Web: existing modular JavaScript foundation
